# 饭格使用指南

## 创建和编辑分区

点击菜单栏饭碗图标打开设置，使用 `+` 新建分区。开启编辑模式后，拖动分区标题改变位置，拖动右下角改变大小。分区的 `…` 按钮打开更多设置；编辑面板保持在分区上方。

普通分区用于整理桌面项目，拖入后吸附到空位；移动分区时，绑定图标一起归位。设置窗口可切换“大图标”和“列表”，并控制“是否可收起”。允许收起时，点击左上角箭头即可展开或收起。

## 映射真实文件夹

设置窗口每个分区都有文件夹按钮。灰色表示尚未映射；点击后在系统选择面板中选取文件夹，并允许访问。映射后，分区实时显示该目录的直接子项；文件较多时可上下滚动。

将桌面或其他位置的文件拖入映射分区，会把文件实际移动到对应目录。映射分区中的文件仍保存在该目录，解除映射或删除分区不会删除它们。同名冲突会停止移动并提示，不会覆盖原文件。

## 文件排序

对映射分区或列表分区，点击该分区的 `…`，在“更多设置”里找到 **文件排序**：

- 排序依据：名称、修改时间、创建时间、大小或类型；
- 顺序：升序或降序；
- 可选择文件夹优先。

排序是饭格自己的分区设置，不会改动 Finder 窗口的排序偏好。普通大图标分区使用桌面网格位置，可在更多设置里调整行列和间距。

## 图标显示与展开收起

可收起分区使用饭格绘制的文件图标，临时隐藏对应 Finder 原图标。收起只隐藏分区内容，不移动文件；展开会复用已准备的图标，避免每次切换都重新加载。退出饭格后恢复原图标。普通列表只显示小图标和文件名；双击文件可打开。

## 分区外观

每个分区可独立调整名称、主色、透明度、双色渐变、标题材质、字号、边框、背景材质和磨砂玻璃。普通大图标分区还支持固定网格、间距和底部延伸。

## 更新和登录时启动

菜单栏“检查更新…”会显示 GitHub 新版本及更新说明，确认“一键更新并重启”后下载安装。安装前校验 SHA-256、应用标识、版本、签名与架构；启动失败时恢复旧版。每次启动还会自动检查一次，有新版本才弹出提示，自动检查失败不打扰使用。

设置窗口可开启登录时启动。移动 App 后，建议关闭并重新开启，使登录项记录新路径。
