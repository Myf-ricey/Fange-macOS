# 饭格使用指南

## 普通模式

普通模式保留 Finder 的日常交互。桌面图标可以照常双击打开，也可以拖入饭格分区。拖动时，分区会显示可用空槽；松手后图标自动吸附到最近位置。

## 编辑模式

从菜单栏或设置窗口开启“编辑模式”：

- 拖动分区标题区域改变位置；
- 拖动右下角改变大小；
- 点击设置窗口的 `+` 创建更多分区；
- 使用删除模式移除不需要的分区；
- 退出编辑模式后恢复正常 Finder 操作。

## 分区外观

每个分区都可单独调整：

- 名称、主色与透明度；
- 纯色或八个方向的双色渐变；
- 标题栏材质、高度、字号、颜色和粗细；
- 背景材质、磨砂玻璃与边框；
- 网格行列、图标间距与底部延伸。

## 代表性风格

- **AI**：光刻电路背景、石墨渐层标题，适合冷色科技主题。
- **实用工具**：叠层玻璃背景、墨黑标签，适合通用工具归类。
- **学业**：云龙纤维纸背景、纸签标签，适合资料与学习内容。

## 自动按类型整理

“自动按类型整理桌面”会根据文件夹、媒体、文档、应用等类型重新摆放图标。执行前会再次确认。它不会移动、删除或改名任何文件。

## 登录时启动

设置窗口可以开启登录时自动启动。移动 App 位置后，建议先关闭再重新开启该选项，使登录项记录新的路径。
