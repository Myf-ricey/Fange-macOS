# 常见问题

## 饭格会移动或删除我的文件吗？

普通分区主要调整桌面图标位置。映射分区接收拖入文件时，会将它实际移动到用户所选文件夹；同名冲突会提示并停止。解除映射或删除分区不会删除对应文件夹及文件。

## 排序设置在哪里？

映射分区或列表分区点击 `… → 文件排序`，可选择名称、修改时间、创建时间、大小、类型，以及升降序、文件夹优先。它独立于 Finder 窗口排序。普通大图标分区使用网格位置。

## 关闭饭格后图标会怎样？

请从菜单栏正常退出。饭格会恢复临时隐藏的 Finder 原图标；文件保留在桌面或实际映射目录。异常退出后，下次启动会读取隐藏记录并恢复处理。

## 为什么首次打开需要系统确认？

当前 Beta 使用 ad-hoc 签名，未完成 Developer ID 签名与 Apple 公证。尝试打开后，可在“系统设置 → 隐私与安全性”中选择“仍要打开”并按系统提示确认，详见[安装指南](INSTALL.md)。

## 为什么需要 Finder 和文件夹权限？

Finder 自动化权限用于读取和调整桌面图标坐标；文件夹权限用于显示映射内容及执行用户拖入的文件移动。
