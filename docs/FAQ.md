# 常见问题

## 饭格会移动或删除我的文件吗？

不会。饭格只要求 Finder 调整桌面图标坐标，不修改文件内容，不移动、删除或改名文件。

## 为什么首次启动需要在“隐私与安全性”中确认？

当前 GitHub Beta 尚未完成 Developer ID 签名与 Apple 公证，因此 macOS 无法自动验证开发者身份和公证状态。第一次双击并看到提醒后，请前往“系统设置 → 隐私与安全性”，点按“仍要打开”并确认一次。系统保存例外后，之后即可正常双击启动。

## 为什么需要控制 Finder？

因为桌面图标仍由 Finder 管理。饭格需要读取图标位置，并在吸附、分区变化或自动整理后请求 Finder 调整位置。

## 关闭饭格后文件会怎样？

文件仍在原来的桌面目录，不会进入饭格专用文件夹。关闭饭格后只是不再显示分区背景。

## 图标大小能否按分区分别设置？

不能。Finder 只提供整个桌面的统一图标大小；饭格可以按分区调整网格行列和间距。

## 是否收费？

当前公开版本全功能免费，没有订阅或功能付费墙。

## 是否开源？

不开放源代码。GitHub 仓库用于官方下载、版本说明和问题反馈。
